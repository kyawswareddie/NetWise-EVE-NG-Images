## 📥 How to download & use an image

1. Find the image in the tables below and click **Download** (opens Google Drive).
2. In Drive, click the download icon and save the file to your PC.
3. Upload it to your EVE-NG: **Main Menu → HTML5 Console / FileZilla / WinSCP** to `/opt/unetlab/addons/qemu/` in the folder name shown in the table.
4. Fix permissions in EVE-NG terminal:
   ```
   /opt/unetlab/wrappers/unl_wrapper -a fixpermissions
   ```
5. Create a new lab and add the node — the image will appear in the node list.
